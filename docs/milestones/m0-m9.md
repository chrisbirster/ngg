# M0–M9 acceptance record

## M0 — Architecture
Game route, manifest contract, local/external player boundary, responsive page regions.

## M1 — Global shell
NGG identity, five primary sections, search, authentication entry points, category strip.

## M2 — Game page
Title, creator, genres, game column, sidebar column, mobile stacking.

## M3 — XO player
Scoreboard, field markings, 22 markers, ball, routes, down/distance and animation.

## M4 — Coaching controls
Offense/defense/special teams tabs, formation and play controls, run-play action and recent-play feed.

## M5 — Metadata
Typed title, creator, description, genres, tags, runtime, capability, dates, URL and launch mode.

## M6 — Sidebar
Cover, CTA, metadata, creator link, tags and tag/genre-oriented recommendation slots.

## M7 — Social
Like, comment, share, playlist and report UI backed by bounded Go JSON endpoints.

## M8 — Promotion
Original reusable banner with independent NGG copy and imagery.

## M9 — Polish
Dark visual system, yellow action accent, responsive grids, hover feedback, sticky desktop sidebar, animated game state.

## Production definition of done

The implementation is a functional vertical slice. Production persistence, identity, moderation operations, analytics, iframe allowlisting, and creator tools remain explicitly post-slice work.
